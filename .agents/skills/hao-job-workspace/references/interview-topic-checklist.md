# 按需选择的面试主题

只有当前岗位或问题涉及某一主题时才读取对应部分。清单迁自面试准备的选题参考，不是标准答案、学习课程或必须逐项完成的能力表。回答概念题时使用当前可核对的技术资料；问到个人经历时再读取对应事实，不从清单推定用户做过这些技术。

## AI Agent

- Data Agent：意图路由、指标目录、语义模型、查询生成与校验、执行边界、图表与有依据的回答、trace 和失败案例。
- Memory：来源片段与记忆候选、策略判断、人物和任务范围、确认与有效期、原始内容存储边界、引用与反馈。
- RAG：导入与切分、embedding、检索与 top-k 取舍、提示构建、引用、检索评估。
- Tool calling：工具 schema、参数校验、应用层执行、结果返回、错误处理。
- Streaming：SSE、增量状态、错误与结束事件、重试与超时。
- 评估：可复现用例、回归、grounding、幻觉与边界检查、隐私泄露检查。

可用追问：一次工具超时后，你会怎样区分模型决策、应用重试和最终结果？让候选人解释具体流程，不要求套用某个项目。

## Python 后端

- 类型与模型：union、`Literal`、`TypedDict`、`Protocol`、泛型、dataclass 与 Pydantic 的验证和序列化。
- API：FastAPI 路由、依赖注入、请求与响应模型、一致的错误表达；传输、业务与持久化模型的边界。
- 并发与可靠性：`async` / `await`、并发限制、超时、重试、同步与后台任务的选择。
- 测试：fixture、参数化、monkeypatch、临时目录、API client、外部依赖替身；正常、边界、拒绝、超时与依赖失败路径。

可用追问：为外部服务设计超时与重试时，怎样确认失败后没有继续发起请求？

## SQL 与数据建模

- 查询：过滤、排序、聚合、`HAVING`、连接、子查询、`EXISTS` 与 CTE。
- 事务与索引：ACID、隔离级别、单列和复合索引、执行计划。
- 建模：关系与约束、规范化与反规范化、幂等写入。
- MySQL：InnoDB、B+ 树、聚簇与二级索引、覆盖索引、回表、MVCC 与锁、慢查询诊断。

可用追问：给定真实查询条件，如何选择复合索引的列顺序，并用什么证据判断是否有效？

## JavaScript、TypeScript 与前端

- JavaScript：作用域、闭包、原型与 `this`、模块、Promise、`async` / `await`、网络与错误处理。
- TypeScript：type 与 interface、union、泛型、工具类型、`unknown` 与 `any`、类型守卫、判别联合与穷尽检查。
- React：props、state、受控表单、effect、memo、ref、组件边界与加载和错误状态。
- 工程工具：包脚本、Vite、Next.js、client component、类型检查、lint 与 build。

可用追问：如何用判别联合表达请求的等待、成功和失败状态，避免互相矛盾的状态组合？
