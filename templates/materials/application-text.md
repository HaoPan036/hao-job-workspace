# 申请文字模板

将模板复制到自己的忽略目录 `private/` 或包外工作区；按请求选择求职信、普通表单文字或 HR 开场白，不必生成三份。

## 本次要求

| 项目 | 内容 |
|---|---|
| 材料类型、公司与岗位 | 待填写；未知不推断 |
| 实际问题或沟通目的 | 待填写 |
| 语言、字符或篇幅限制 | 待填写；无明确限制时注明 |
| 已确认的经历与事实来源 | 待填写 |
| 可复用的正文位置与版本 | 待填写；没有则注明 |
| 复用方式 | 原文复用，或填写调整所依据的具体问题、语言、长度变化或用户要求 |
| 个人动机或必要承诺的来源 | 按需填写；未确认的内容不补造 |

## 可直接使用的正文

待填写。

求职信交代申请的岗位、相关经历和已确认的动机；表单文字先回答实际问题；HR 开场白简短说明背景、相关经历和沟通目的。已有适用的已确认正文应原文复用；需要调整时只调整要求涉及的部分。
