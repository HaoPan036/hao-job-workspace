# 简历条目模板

将模板复制到自己的忽略目录 `private/` 或包外工作区后填写。只填写本次需要的条目，保留原始简历；下面的输入与检查不必放进最终 CV。

## 本次输入

| 项目 | 内容 |
|---|---|
| 目标岗位与语言 | 待填写 |
| 选定简历、用途与版本 | 待填写 |
| 本次修改范围 | 待填写 |
| 事实卡 ID 与来源位置 | 待填写 |
| 允许使用的范围 | 待填写 |
| 本人具体行动与职责 | 待填写 |
| 已有依据的方法与结果 | 待填写 |
| 必须保留的条件 | 待填写 |

## 修改文本

中文：待填写。

English：按需填写。

可参考“做了什么 + 在什么范围内怎样做 + 有依据的结果”。没有可靠数字时使用准确的定性结果；方法或结果并非每句都必须出现。不要把整个团队成果写成本人负责。

## 核对

- 身份、教育和日期没有因润色改变；职责、实现、使用与结果各有对应依据。
- 事实的允许用途覆盖本次材料，计划和未核实数字没有写成已完成经历。
- 中英文职责、时态、指标口径与限制一致，没有从 JD 补入未使用过的技术。
- 最终条目可直接使用，事实 ID 和检查说明另外保留。
