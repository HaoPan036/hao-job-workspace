# 虚构岗位：Python 开发实习

这是一份从零编写的练习 JD，没有对应公司、地区、职位链接或实际招聘活动。

## 工作内容

- 维护 Python 脚本，处理失败分支并编写测试。
- 向团队说明问题、修改范围和仍未解决的限制。
- 阅读现有代码，区分已有实现与自己的修改。

## 要求与加分项

- 必需：Python 基础、测试思路、清楚说明个人贡献。
- 加分：Kubernetes 使用经验。
