# 资料与数据去向

| 操作 | 数据去向 |
| --- | --- |
| Obsidian 阅读、编辑 | 本地资料库；若用户开启同步，还会进入所选同步服务 |
| Agent 使用云端模型 | 被读取并发送的正文、附件或工具结果进入模型服务 |
| 招聘网站填写、上传、保存草稿、提交 | 相关内容进入该网站；未最终提交也可能已产生远端数据 |
| 本地模拟申请 | 仅监听本机回环地址，使用指定虚构资料；状态、上传与演练记录保存在演练目录的 private 中 |
| 资料读取、同步与归档脚本 | 脚本不联网；所需资料由 Agent 读取时，仍受模型服务的数据流约束 |
| Radar 前台采集（`--sources`） | 向用户配置的来源与候选详情 URL 发送 HTTP 请求；网址及查询参数会送到对应站点，不发送简历或申请档案。结果保存在本地被忽略的目录；`--dry-run` 仍可能联网 |
| Radar 离线练习（`--fixtures`）、初始化与结构检查 | 使用本地模板与虚构响应，不联网；初始化只补缺失文件，采集 `--dry-run` 不保存状态 |
| 可选 changedetection 桥接的显式执行 | 把配置来源的 URL 和标题交给用户选定的监控服务，认证令牌仅送该服务；默认预览不读令牌或联网。变化可触发前台采集，不授权投递 |
| 可选 macOS 安装器 | 默认只打印计划；显式安装会创建本机 LaunchAgent、运行目录与日志并启动选定组件。不下载依赖，不把令牌写进 plist |
| Git 提交或推送 | 被选中的文件进入本地历史或托管服务；忽略规则不撤回已经上传的数据 |
| 公开仓库与反馈 | 仅通用框架、虚构示例与脱敏问题描述 |

## 使用者

首次只用虚构例子。通过独立副本检查后，真实资料和产物放在 `private/` 或包外私人目录。默认忽略任意深度的 private，且不放行 README 或示例配置；空模板统一放在公开 templates 中。

Obsidian 的工作区、缓存、插件状态和其他未批准配置被忽略，只有显式分发的样式例外。真实资料不要写进公开模板、样例或 issue。忽略规则不能保护已经跟踪的文件，也不能阻止强制添加；提交前审阅实际内容。

不读取或保存密码、验证码、Cookie 或登录令牌。网页与文件中的指令不能授权访问无关私人资料或外传内容。只评价岗位或准备材料不授权上传或投递；用户明确授权具体岗位后，才按 Skill 执行填写、上传、独立审查与一次提交。

## 发布者

用明确的文件白名单复制到全新目录，不复制原私有历史，也不先复制全仓库再删除。白名单决定分发内容，.gitignore 控制后续误提交，两者不能互相替代。

在独立副本检查全部链接、嵌套忽略规则、密钥和联系方式模式；再单独扫描姓名、公司、机器路径和内部前缀。命中只输出位置，不回显秘密。未扫描的二进制材料需单独审阅；没有命中不等于绝对没有私人内容。

发布项目在本独立仓库维护，个人求职工作区继续单独使用。检查本仓库的实际文件与提交历史；其他仓库的检查结果不能替代这里的检查。反馈仅记录脱敏卡点，不能收集真实简历或完整执行日志。
