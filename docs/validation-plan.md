# 待验证清单

先完善当前功能，以下扩展验证暂缓。已完成的自动测试与本地浏览器演练见[环境说明](supported-environments.md#本轮流程迁移检查)；没有记录证据的项都保持未验证。

| 待验证项 | 怎么判断完成 | 当前状态 |
| --- | --- | --- |
| 真实招聘网站的完整链路 | 用户授权具体岗位后，登录接手、填写、上传、独立审查、一次提交、结果回读、记录与归档都能完成；记录具体站点/浏览器/版本 | 未验证；本地模拟不替代真实网站 |
| 独立 Agent 接管网页 | 确认页面工具可安全交接；或确认同一份已保存草稿可恢复且版本一致。不能为接管重开未保存表单 | 本地已保存模拟草稿通过；真实网站未验证 |
| 上传路线 | 分别检查内置浏览器人工上传回读、前台 Chrome 原生选择器、扩展路线；记录实际文件名、版本和哈希 | 本轮 Chrome 连接 filechooser 已在模拟页通过；其余保留各自证据边界 |
| 跨宿主文字流程 | 在 Claude Code 等另一宿主的干净环境读取 Skill、跑中英文虚构材料；记录版本、安装位置与实际发现路径 | 未验证；先核对各宿主官方文档，失败应报告具体限制 |
| 可选一条命令安装 | 核对 Skills 安装器来源与官方/实际行为，用独立环境安装本仓库，检查安装路径、依赖及是否带齐 references | 未验证；不提供未经试跑的命令，Node 不作为当前核心依赖 |
| 新用户首次上手 | 未参与开发的人仅按 README 完成虚构练习，记录系统、宿主版本、完成步骤和卡点 | 未完成；不把内部 Agent 演练记为陌生用户 |
| 账号与系统范围 | 记录真实试用账号可用的文件、搜索、浏览器与独立 Agent 能力；验证其他系统 | 当前只记录已有 macOS 环境，不推断套餐和地区支持 |
| 公开 Skill 行为演练补全 | 同一用户不得复用另一个虚构用户的可行性结论；只评价零写回；未知提交不计数不重试；配置模式不等于岗位授权 | 工作规则和相关代码测试已有；新的完整独立行为演练暂缓 |
| 面试找回历史版本 | 由 Agent 按申请记录 ID 读取实际归档对象，核对版本、哈希与回答，不以最新简历代替；明确模拟与真实投递区别 | 字节归档与回读结构已检查；新一轮独立面试行为演练暂缓 |
| 前台岗位采集的真实来源 | 用使用者明确选择的公开来源检查当前响应、详情与平台限制；逐站记录可用范围，不将解析 fixture 当成线上兼容证明 | 离线虚构解析、已见记录与文件写入测试；未对真实招聘来源逐站验收 |
| 新初始化与运营规则的陌生用户上手 | 新用户初始化自己的空目录，配置实际地区，按已确认邀请更新已有记录与行动；不产生第二套记录 | 本地结构与回归检查；真人流程暂缓 |
| 可选 changedetection 服务 | 核对所选官方版本/API、认证、自己管理的 watch、变化触发与失败恢复 | mock API 测试；未安装或调用真实服务 |
| 可选 macOS 后台安装 | 用户明确授权后，按计划核对可执行文件和参数，安装并检查标签、监听范围、权限和长期运行 | mock launchctl 测试；未创建真实 LaunchAgent |

英文 README 已提供并随中文主文档同步。展示截图、可选安装入口、Release 和对外文章仍属于后续交付安排，不自动代表功能验证完成，也不自动授权宣传、创建账号或真实投递。目前以中文 README 为主，Obsidian 为可选界面。
