# 网页定时任务与 GitHub 接入

本页保留可选接入说明，不作为本地找岗位流程的前提。公开副本的账号权限和后台执行仍未验证。

官方文档说明网页定时任务可以使用该对话可用的连接工具，实际仓库访问仍受连接权限控制；这不代表任意账号和仓库都已经跑通。[定时任务](https://learn.chatgpt.com/docs/automations)、[插件权限](https://learn.chatgpt.com/docs/plugins#how-permissions-and-data-sharing-work)

迁移时复用已经在用的任务提示词和偏好结构，将个人条件换成用户填写的模板；不另设计岗位队列或账户状态字段。只开放完成过验证的读取和输出方式，不默认增加写回。

需要的资料尽量限定为脱敏搜索画像和公开岗位标识，不让浏览岗位的任务直接读取完整私人档案。连接权限和提示词约定分别检查；只读也不等于消除数据外传风险。

先在普通对话中试一次，再在用户要求创建定时任务时验证后台运行。记录实际读取范围、时间和失败情况，不能将一次前台成功写成无人值守能力已验证。

官方说明核对日期：2026-09-29。数据去向见 [资料说明](../privacy-and-data-flow.md)。
