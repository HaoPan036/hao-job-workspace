# 试用记录

先邀请一两位没有参与开发的人，仅使用虚构资料完成简历与面试流程。反馈不要包含真实简历、联系方式或完整日志。

复制下面的模板，填好后粘贴到本仓库的 [Issue](https://github.com/HaoPan036/hao-job-workspace/issues/new)。版本可用 `git rev-parse --short HEAD` 查看；使用 ZIP 时填写下载日期。账号只记录功能入口是否可见，不填写账号标识或套餐账单。

```text
日期：
仓库提交版本 / ZIP 下载日期：
操作系统及版本：
Obsidian 版本：
Codex 版本：
能否看到 Codex 入口并读取虚构文件：

README 完成到第几步：
仓库检查输出的 errors / warnings 数量：
private 忽略检查是否命中：
是否需要维护者在 README 之外补充说明：

能否根据新证据收窄职责：
能否在简历和面试稿中找到同一事实引用：
是否保留未核实数字、未用技术及双语职责边界：

卡住的步骤：
预期结果：
实际结果（只给脱敏摘要）：
希望改进的说明：

提交前确认：未包含真实简历、联系方式、凭据或完整执行日志。
```

只有使用者自己按文档跑通，才记为“已有别人跑通”。维护者演练、Agent 独立测试和静态检查分别记录，不能替代真实用户。某一步需要口头补充时，先修文档，再重新试该步骤。
