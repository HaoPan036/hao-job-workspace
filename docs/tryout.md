# 试用记录

先邀请一两位没有参与开发的人，仅使用虚构资料完成简历与面试流程。反馈不要包含真实简历、联系方式或完整日志。

记录以下内容：

- 日期与发行副本版本。
- 操作系统、Obsidian 与 Codex 版本；账号能否看到所需入口即可，不记录账号本身。
- 按 README 完成到哪一步，是否需要维护者口头补充。
- 能否用新证据收窄职责，并在简历和面试稿中找到相同引用。
- 未核实数字、未用技术、中英文职责范围是否处理正确。
- 卡住的步骤、错误提示的脱敏摘要、希望改进的说明。

只有使用者自己按文档跑通，才记为“已有别人跑通”。维护者演练、Agent 独立测试和静态检查分别记录，不能替代真实用户。某一步需要口头补充时，先修文档，再重新试该步骤。
